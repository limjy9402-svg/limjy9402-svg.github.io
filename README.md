# limjy9402-svg.github.io

임지연(Jiyeon Lim)의 개인 홈페이지 — https://limjy9402-svg.github.io

## 구조
- `index.html` — 페이지 본문 (About / Education / Projects / Contact)
- `style.css` — 스타일
- `404.html` — 404 페이지
- `favicon.svg` — 파비콘

## 로컬에서 실행
```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 수정 & 배포
`index.html`을 고친 뒤 `main` 브랜치에 push하면 GitHub Pages가 자동으로 배포합니다 (Actions 탭에서 확인).
